Démonstrateur d'Intégration Tag Commander

Testez le module de reprise sous ses 3 modes d'affichage pilotables via Tag Manager.

Méthode d'implémentation dans Tag Commander

Dans l'interface Tag Commander, créez un **Tag Custom HTML / JS** qui charge le script et applique l'option de votre choix :

<!-- Tag Custom dans Tag Commander -->
<script type="text/javascript">
(function() {
    var tcScript = document.createElement('script');
    tcScript.src = 'https://mon-cdn.com/tradein-module.js';
    tcScript.async = true;
    
    tcScript.onload = function() {
        if (window.TradeInModule) {
            // Option 1 : Popin centrée
            // window.TradeInModule.init({ displayType: 'popin' });

            // Option 2 : Tiroir à droite
            // window.TradeInModule.init({ displayType: 'drawer-right' });

            // Option 3 : Tiroir à gauche
            window.TradeInModule.init({ displayType: 'drawer-left' });
        }
    };
    
    document.head.appendChild(tcScript);
})();
</script>
Astuce Tag Commander :

Vous pouvez lier l'option displayType à une variable du conteneur Tag Commander (ex: tc_vars["tradein_display"]) pour modifier dynamiquement le comportement d'affichage sans retoucher au code du site hôte.
